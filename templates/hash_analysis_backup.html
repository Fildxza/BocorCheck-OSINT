📚 Technical Explanation:

Why {{ report.hash_algorithm }}?

    {% if report.hash_algorithm == 'MD5' %}
  • MD5 is cryptographically broken (proven since 2004)
  • Can be cracked in SECONDS using GPU/ASIC hardware
  • Rainbow tables available freely online
  • Cost: $0 - essentially free to crack
  • Action: Assume password is compromised. Change immediately.
    • {% elif report.hash_algorithm == 'SHA1' %}
  • SHA1 is cryptographically broken (proven in 2017)
  • Practical collision attacks have been demonstrated
  • Can be cracked in MINUTES to HOURS
  • Action: Change password immediately. Assume compromise.
    • {% elif report.hash_algorithm == 'SHA256' %}
  • SHA256 is still cryptographically sound
  • However, unsalted SHA256 is vulnerable to rainbow tables
  • Can be cracked in hours to days on consumer hardware
  • Salted version is more secure (takes months/years)
  • If password is strong (12+ chars, mixed case + numbers + symbols): Acceptable risk
    • {% elif report.hash_algorithm == 'bcrypt' %}
  • bcrypt is industry-recommended for password hashing
  • Includes automatic salting and adaptive cost factor
  • Would take YEARS to DECADES to crack with brute force
  • Security scales with time (gets harder each year as computers faster)
  • If password strong: Very low immediate risk. Monitor accounts.
    • {% elif report.hash_algorithm == 'Argon2' %}
  • Argon2 is the MODERN BEST PRACTICE (since 2015)
  • Memory-hard algorithm - resistant to GPU/ASIC attacks
  • Would take MONTHS/YEARS+ even with specialized hardware
  • Very secure. Monitor accounts as precaution, but low risk.
    • {% else %}
  • Algorithm: {{ report.hash_algorithm }}
  • See reference table below for details
    • {% endif %}
