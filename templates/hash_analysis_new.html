Hash Algorithm Reference Guide
Secure Algorithms
  • bcrypt - Adaptive hashing with salt, resistant to modern attacks
  • scrypt - Memory-hard function, excellent password security
  • Argon2 - Winner of Password Hashing Competition, recommended standard
  • PBKDF2 - Key derivation function with configurable iterations
Weak Algorithms
  • MD5 - Cryptographically broken, should never be used
  • SHA-1 - Deprecated, vulnerable to collision attacks
  • SHA-256 (unsalted) - Rainbow table vulnerable, need salt
  • Plain text - No hashing, critical security risk
